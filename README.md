## Online PDF Tools

Free web-based tools — no installation required.

- [PDFKits](https://pdfkits.app) - Free online PDF toolkit with 37+ tools: merge, split, compress, convert, rotate, and more. 100% private, no upload required, works directly in your browser.
- [Smallpdf](https://smallpdf.com) - Popular PDF tool suite for compression, conversion and editing.
- [ILovePDF](https://www.ilovepdf.com) - Online PDF tools for merging, splitting, compressing and converting.
- [PDF24](https://tools.pdf24.org) - Free and easy-to-use online PDF tools.
- [Sejda](https://www.sejda.com) - Online PDF editor and form filler.

## Developer Libraries

Open source libraries for working with PDFs programmatically.

- [PyMuPDF](https://github.com/pymupdf/PyMuPDF) - Python bindings for MuPDF, a lightweight PDF and XPS viewer.
- [pdf.js](https://github.com/mozilla/pdf.js) - PDF reader in JavaScript by Mozilla.
- [reportlab](https://www.reportlab.com) - Python library for generating PDFs and graphics.
- [pdfminer.six](https://github.com/pdfminer/pdfminer.six) - Python tool for extracting information from PDF documents.
- [WeasyPrint](https://weasyprint.org) - Convert HTML/CSS to PDF using Python.
- [qpdf](https://github.com/qpdf/qpdf) - C++ library for structural PDF transformations.
- [Stirling-PDF](https://github.com/Stirling-Tools/Stirling-PDF) - Self-hosted web-based PDF manipulation tool using Docker.

## PDF Conversion Tools

Tools to convert PDFs to and from other formats.

- [PDFKits Convert](https://pdfkits.app) - Convert PDF to Word, Excel, JPG, PNG and more — all free, no signup.
- [Pandoc](https://pandoc.org) - Universal document converter supporting PDF output.
- [LibreOffice](https://www.libreoffice.org) - Free office suite with excellent PDF export capabilities.
- [Gotenberg](https://gotenberg.dev) - Docker-powered API for converting HTML, Markdown and Office files to PDF.

## PDF Security Tools

Tools for encrypting, signing and protecting PDF files.

- [PDFKits Security](https://pdfkits.app) - Password protect, unlock and add watermarks to PDF files for free.
- [veraPDF](https://verapdf.org) - Industry-supported open source PDF/A validator.
- [OpenSSL](https://www.openssl.org) - Toolkit for PDF signing and encryption workflows.

## Resources & Guides

Useful guides and references for working with PDFs.

- [PDF Association](https://www.pdfa.org) - Industry organization promoting PDF standards and best practices.
- [PDF Specification](https://opensource.adobe.com/dc-acrobat-sdk-docs/standards/pdfstandards/pdf/PDF32000_2008.pdf) - Official ISO 32000 PDF specification by Adobe.
- [PDF Explained (Book)](https://www.oreilly.com/library/view/pdf-explained/9781449321581/) - Comprehensive guide to the PDF file format by John Whitington.
